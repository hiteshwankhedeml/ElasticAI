# Create Agent

**Technical Requirements:**

* Unity catalog
* Compute



**Create Genie Agent:**

1. Click **Genie Agents** in the sidebar.
2. Click **New** in the upper-right corner of the screen.
3. Choose the data sources that you want to include in your Genie Agent. Then, click **Create**.
4. Add Description, Instructions

* When you add data assets to an agent, Genie automatically searches for relevant popular workspace queries associated with those assets
* Genie can query tables beyond those explicitly added to an agent.&#x20;
* Access is controlled by Unity Catalog permissions, not by the Genie Agent itself
* We can share agent with others
