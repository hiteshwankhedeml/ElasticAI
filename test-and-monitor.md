# Test and Monitor

* Test it with realistic questions that you expect your business users to ask.
* Like other large language models (LLMs), Genie can exhibit non-deterministic behaviors.&#x20;
* This means that you might occasionally receive different outputs when submitting the same prompt multiple times.&#x20;
* Providing example SQL queries that Genie can learn from can help make Genie more consistent

**Response Feedback:**

* Users can give feedback with explanation
* Can also request for review
* As an editor, you can view feedback and flagged responses in the Genie interface.
* You should use feedback to identify improvement opportunities or respond directly to user questions



**Debug Response with Genie Code:**

1. Open Genie Code from the response.
2. Describe the problem and the behavior you want.
3. Review the context changes that Genie Code proposes, and accept the ones you want to keep.



**Monitor the Agent:**

* Use the **Monitor** tab to review individual questions and responses, view user feedback, and identify responses flagged for review.



&#x20;**Analyze Space Usage:**

* This launches Genie Code, which reviews the user messages, feedback, and issues from the last seven days and reports on common topics, recurring issues, and suggested context improvements.
