# Setup Environment

* [Install or update the Databricks CLI](https://learn.microsoft.com/en-us/azure/databricks/dev-tools/cli/install).
* [OAuth user-to-machine (U2M) authentication](https://learn.microsoft.com/en-us/azure/databricks/dev-tools/cli/authentication#u2m-auth).
* pip3 install databricks-sdk
* pip3 install databricks-sql-connector
