# Linear Retrievers

* &#x20;**Linear retrievers** are designed to simplify the process of searching across both semantic and non-semantic fields in a weighted linear fashion while optionally normalizing scores
* You can use linear retrievers to create hybrid search solutions by combining semantic and non-semantic search methods
* You can boost certain fields to give them more importance in the search results. Note that boosting is not possible for Reciprocal Rank Fusion (RRF) retrievers
