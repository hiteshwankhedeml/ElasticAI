# Configure Permissions

* What users can do with Databricks apps, such as accessing, managing, and sharing apps.
* `CAN MANAGE` - Can manage app settings and permissions, including the ability to edit and delete the app. Includes all `CAN USE` capabilities.
* `CAN USE` - Can run and interact with the app but can't modify or manage it.
* Only users with `CAN MANAGE` permissions can assign or revoke permissions on an app.
