# Genie Code

* Genie Code is billed following a pay-as-you-go pricing model that includes a per-user free monthly allowance.
* Can only access data and perform operations that you have permissions for



Usage:

* Empty Notebook ⇒ Genie Code ⇒ Enter prompt ⇒ Can also use @ to add tables etc
* We can also ask it to train ML model
  * Setting ⇒ Instructions ⇒ There are user as well as workspace instruction
* We can also use it to create dashboard ⇒ Create 5 visualization from our table



**Capabilties:**

* Data science and ML notebooks
* Piepline development in Lakeflow
* Data analysis in dashboards
* Observability and evaluation in MLflow
