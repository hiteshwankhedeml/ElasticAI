# Embed a Genie Agent in an external app

* End user must have explicit access to the Genie Agent and the underlying data assets it uses.&#x20;

**Step 1: Configure embedding surface**

* A workspace admin must configure allowed embedding surfaces before a Genie Agent can be embedded

**Step 2: Generate the iframe code**

1. Open the Genie Agent you want to embed.
2. Click **Share**.
3. In the Share dialog, click **Embed space**.
4. Copy the generated iframe code.

**Step 3: Add the iframe to the application**

* Paste the iframe code into your external website or application.
