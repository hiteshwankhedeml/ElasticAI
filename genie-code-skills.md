# Genie Code Skills

* Skills package domain-specific knowledge and workflows
* Genie Code can load when relevant to perform specific tasks
* Skills can include guidance, best practices, reusable code, and executable scripts.
* Unlike [custom instructions](https://learn.microsoft.com/en-us/azure/databricks/genie-code/instructions), which are applied globally, skills are loaded automatically and only in the relevant context
* You can also manually invoke skills by `@` mentioning them.
* Types of Skills
  * Workspace skills
  * User skills
* Use clear name and description with with detailed instructions
* Version control your skills with Databricks git folder
